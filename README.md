# Bengaluru Environment Map

Ward-by-ward heat, greenery, lakes, industry, major roads and waste sites for Bengaluru (BBMP, 243 wards),
with live air readings for the selected ward.

    npm install
    npm run data   # rebuild public/data from open sources (cached in data/raw)
    npm run dev

Sources and the per-ward calculations are documented at the top of `scripts/build-data.mjs`.
